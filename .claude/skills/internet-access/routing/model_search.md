# 大模型联网搜索

用于模糊需求、跨语言发现、跨来源综合或用户明确指定的联网搜索。单个已知版本和 URL 不必升级。这里定义调用与验收要求，不在 Skill 内实现 Provider SDK、代理服务或另一份能力注册表。

## 先验证能力

复用当前运行时或 owner 提供的工具、API 与授权。普通文本生成不等于联网搜索；模型名、厂商宣传和历史配置不能证明本次调用确实搜索了。

从当前工具 schema、官方版本合同和实际响应确认任务需要的能力：网页/X 等来源覆盖、时间与域名过滤、引用 URL、分页、地域语言、访问身份、成本计量。只检查本次需要的字段。区分“支持”“不支持”“未知”，不猜测参数或编造 CLI 命令。

用户指定后端时优先使用；不可用就说明缺口。切换后端若改变费用、数据接收方或访问范围，先核对已有授权。缺少凭据时仍可完成公开来源检索和查询设计，不自动申请账号或安装插件。

## 查询与核验

1. 将需求拆成主体、目标、时间、来源和必要过滤。例如“类似这条视频的转场”先提取转场特点，而非只搜索“好看的视频”。
2. 先执行一个小查询批次。已有本地分析结果可帮助生成同义词、中英文表达和平台查询；模型生成的关键词属于检索计划，不是事实证据。
3. 接收候选时保留原始 URL、标题、匹配理由、发现后端和查询；有依据才记录作者、发布时间、读取时间和费用。缺失字段标记未知。
4. 打开支持关键结论的原始来源。保留“模型摘要”和“实际读到的内容”的区别；链接不可访问或不支持主张时不得计为已核实。
5. 去掉跟踪参数时保留内容身份参数；按 canonical URL、平台内容 ID、仓库或作品身份去重。多个模型引用同一篇报道不算独立佐证。
6. 证据薄弱时按缺口扩展一轮；停止和样本完成条件沿用 research_budget.md，不因调用多个模型就宣称全面。

## 成本、隐私与恢复

- 默认使用一个合适的后端，不并行询问所有模型。比较多个后端只在用户要求或存在明确证据缺口时进行。
- 复用本任务已核验来源；历史缓存标记时间。明确要求当前状态时刷新关键证据。
- 不把私密帖子、登录页面、cookie、本地文件或整个分析库自动传给新的外部模型。仅传任务需要且获授权的数据。
- 搜索与分析分别计入已授权预算；成本未知不能标作免费。请求超时且可能已计费时先查询原 operation，不按普通只读网页重试规则重复付费。
- 若返回只有生成文本、没有可核查来源，标记为未核实建议，使用现有普通搜索补证；不能虚构引用。

## 交付

先给结论或候选，说明与需求的关联，并附直接来源。只有影响结论时才解释后端差异和覆盖限制。不默认展示原始响应、模型内部推理或搜索流水账。

若用户明确要求实现搜索适配器，进入现有工具/网关 owner 核对合同后实现；上述字段只是互操作要求，不代表当前已有统一 API。
