# 决策步骤

工具选择统一参照 [入口路由表](../SKILL.md#按交付目标路由)，不在本文件维护第二份顺序。

1. 确定交付物：事实、字段、研究样本、媒体文件，还是实际页面行为。组合任务按依赖执行，不强制走完所有等级。
2. 用户已给来源就定向读取；未知来源才先发现。截图、会话与 UI 回归直接选浏览器。
3. 只加载对应专项。简单事实用 lightweight；关键主张核验用 standard + evidence_policy；明确大样本用 deep_research。
4. 检查内容是否满足字段、时效、身份和数量要求；符合就结束，不为了多源数量继续搜索。
5. 不足时明确缺的证据，按入口恢复表升级；不存在必经的 Firecrawl → Playwright 链。

一次查询不创建新封装。批量任务可使用临时脚本保存进度；长期自动化进入所属项目。新增工具安装、付费调用和外部写入不能从路由推导授权。
