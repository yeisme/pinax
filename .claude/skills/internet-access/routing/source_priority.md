# 来源判断

工具选择只见 [入口路由表](../SKILL.md#按交付目标路由)。本文件补充来源选择原则。

- 明确 URL、仓库、包名或 API 时直接读取；gh 只适用于 GitHub。
- 技术合同优先官方文档、标准、版本说明；当前字段优先对应 API/registry；页面行为使用浏览器证据。三者冲突先检查版本、时间、身份与范围。
- 平台已有可用后端就直接用；Agent Reach 是能力诊断入口，不是每次读取的必经包装。
- 本机端口、缓存、Research Harness 和 Gateway 规则只在用户指定该环境时加载 local_research_infra，不影响普通联网任务。
- 搜索摘要用于发现线索；关键结论需打开原始来源。转载与镜像不能当作独立佐证。
- 指定来源不可读时保留该缺口；替代来源不能默默冒充用户指定来源。
